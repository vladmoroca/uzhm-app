# Жести в текст — застосунок для телефона

Веб-застосунок (PWA): відкривається в браузері телефона, ставиться на головний екран як звичайна програма і працює без інтернету.

```
камера / відео з галереї
  -> MediaPipe Pose + Hand (на телефоні)
  -> 30 кадрів/с, ознаки v2 (той самий код, що й у навчанні, перенесений на JS)
  -> ОФЛАЙН: модель ключових слів (ONNX) на телефоні
  -> ОНЛАЙН: на сервер (ПК) ідуть лише координати точок, не відео ->
             ансамбль моделей + речення від локальної LLM (Ollama) лише з упевнених слів
```

## Структура

| Що | Де |
|---|---|
| Застосунок | `www/` (index.html, js/, model/, vendor/) |
| Перенесений конвеєр ознак | `www/js/features.js` — збігається з `sign_data.py` (різниця ймовірностей слів ~1e-5) |
| Запуск усього (сервер + тунель + QR) | `start.bat` -> `run.py` -> `server/server.py` |
| Експорт нової моделі | `update_model.bat [чекпоінт]` — за замовчуванням kw_concept_s0 (інакше kw_conv_s0) (`export/…`; один раз `pip install onnx onnxruntime`) |
| Список файлів для офлайн-кешу | `build.py` -> `www/sw.js` (запускати після будь-якої зміни в `www/`) |

## Запуск

Двічі клацнути **`start.bat`**. Він:
1. сам встановить `fastapi`/`uvicorn`, якщо їх немає;
2. запустить сервер;
3. відкриє https-тунель — спершу Cloudflare (до 3 спроб), якщо не вийде, то localhost.run через ssh;
4. надрукує адресу для телефона і QR-код до неї.

Якщо тунель обірветься, `start.bat` сам відкриє новий. Ctrl+C зупиняє все.

- **На ПК:** http://localhost:8000. Вебкамера працює і без https.
- **На телефоні:** відскануй QR-код і вибери в меню браузера «Додати на головний екран».
- **Тільки сервер, без тунелю:** `start.bat --no-tunnel`.
- **Якщо жоден тунель не відкрився**, `start.bat` підкаже варіант для Android + Chrome у тій самій Wi-Fi: прапорець `chrome://flags/#unsafely-treat-insecure-origin-as-secure` з адресою `http://IP-ПК:8000`.

`cloudflared.exe` збирається з двох частин у `tools\` — це офіційна збірка Cloudflare 2026.10.0.

## Режими

- **Офлайн.** Усе рахується на телефоні. Після першого відкриття застосунок і моделі (~70 МБ) лежать у кеші, тож працює навіть у режимі польоту. Перевірити: увімкнути режим польоту і відкрити іконку.
- **Онлайн.** Ансамбль двох моделей: пара `kw_concept_s0/s1` (інакше `kw_conv_s0/s1`); своя — `start.bat --ckpt шлях1 шлях2`. Речення складає локальна модель Ollama, якщо вона запущена (вибирається автоматично; своя — `start.bat --llm назва`, вимкнути — `start.bat --llm none`). Без Ollama сервер показує лише слова.
  - Речення складається лише з ≥2 упевнених слів. Мовній моделі заборонено додавати імена, числа, місця та інші нові змістовні слова.
  - Адреса quick-тунелю щоразу нова. Застосунок, встановлений зі старої адреси, далі працює офлайн, а для онлайн-режиму нову адресу вписують у «Налаштування → Адреса сервера».

## Способи розпізнавання

- **Запис речення** — записати одне речення (2–10 с) і отримати слова.
- **Наживо** — щосекунди розпізнаються останні 4 с, впевнені слова додаються в рядок під відео. Працює завжди на телефоні.
- **Відео з галереї** — те саме, що запис, але з готового файлу.
- **⟲** перемикає всі камери телефона по черзі: фронтальну, задню, ширококутну тощо.
- **Підлаштування під людину.** Якщо модель навчена з `--adapt`, застосунок нормалізує жести статистикою поточної людини, і перші 10–20 с вона «звикає» до мовця. Для іншої людини треба натиснути «Нова людина». В онлайн-режимі ця статистика (лише суми чисел) іде на сервер разом із точками.

## Порогові значення

- «Упевнено» (0.90) і «можливо» (0.75) змінюються в налаштуваннях.
- На новій для моделі людині слово з імовірністю ≥0.9 правильне приблизно в 1 з 3 випадків, з ≥0.95 — приблизно в половині.
- Нижче порогів застосунок нічого не показує: це свідомо, щоб не видавати шум за переклад.

## Якщо щось не працює

- **Камера не вмикається:** сторінку відкрито не через https чи localhost, або не надано дозвіл.
- **Детекція дуже повільна або падає:** додати `?cpu` в кінці адреси (детектор перейде з GPU на CPU).
- **Застосунок не оновився після змін:** запустити `python build.py`, потім перевідкрити сторінку з інтернетом (старий кеш заміниться).
- **Відео з галереї не відкривається:** формат не підтримується браузером. MP4 (H.264) з телефона підтримується.
